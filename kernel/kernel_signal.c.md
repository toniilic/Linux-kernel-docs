# kernel/signal.c - Linux Signal Handling Implementation

## Overview

This file implements the core signal handling mechanism in the Linux kernel, originally written by Linus Torvalds in 1991-1992. It provides the fundamental infrastructure for inter-process communication through signals, supporting both traditional Unix signals and POSIX real-time signals. The implementation handles signal generation, delivery, queuing, and processing while maintaining compatibility with multiple signal standards and ensuring secure signal operations across process boundaries.

## Historical Development

### Key Contributors and Milestones
- **Linus Torvalds (1991-1992)**: Original signal implementation

## Core Concepts

### Signal Types and Categories

#### Standard Unix Signals (1-31)
- **SIGKILL**: Unconditional termination (cannot be caught/ignored)
- **SIGSTOP**: Unconditional stop (cannot be caught/ignored) 
- **SIGTERM**: Termination request (can be caught)
- **SIGINT**: Interrupt from keyboard (Ctrl+C)
- **SIGCHLD**: Child process status change
- **SIGSEGV**: Segmentation violation
- **SIGPIPE**: Broken pipe
- **SIGALRM**: Timer expiration

#### Real-Time Signals (32-64)
- **Queueable**: Multiple instances can be queued
- **Prioritized**: Higher numbered signals have higher priority
- **Reliable Delivery**: Guaranteed delivery order and information
- **Extended Information**: Can carry additional data (siginfo_t)

### Signal States and Processing
```
Signal Generation → Signal Queuing → Signal Delivery → Signal Handling
       ↓                  ↓               ↓               ↓
  [Sender Process] → [Pending Queue] → [Target Process] → [Handler/Action]
```

### Signal Delivery Mechanisms
- **Synchronous**: Generated by the process itself (SIGSEGV, SIGFPE)
- **Asynchronous**: Generated by external events (SIGINT, SIGTERM)
- **Process Groups**: Signals sent to entire process groups
- **Session Groups**: Signals affecting terminal sessions

### Signal Information Structure
```c
typedef struct kernel_siginfo {
    int si_signo;                   /* Signal number */
    int si_errno;                   /* Error number */
    int si_code;                    /* Signal code */
    
    union {
        /* SIGKILL, SIGTERM, etc. */
        struct {
            __kernel_pid_t _pid;    /* Sending process PID */
            __kernel_uid32_t _uid;  /* Sending process UID */
        } _kill;
        
        /* SIGCHLD */
        struct {
            __kernel_pid_t _pid;    /* Child PID */
            __kernel_uid32_t _uid;  /* Child UID */
            int _status;            /* Exit status */
            __kernel_clock_t _utime; /* User time */
            __kernel_clock_t _stime; /* System time */
        } _sigchld;
        
        /* SIGSEGV, SIGBUS, SIGFPE, etc. */
        struct {
            void __user *_addr;     /* Faulting address */
            union {
                short _addr_lsb;    /* LSB of address */
                struct {
                    char _dummy_bnd[__ADDR_BND_PKEY_PAD];
                    void __user *_lower; /* Lower bound */
                    void __user *_upper; /* Upper bound */
                } _addr_bnd;
                struct {
                    char _dummy_pkey[__ADDR_BND_PKEY_PAD];
                    __u32 _pkey;    /* Protection key */
                } _addr_pkey;
                struct {
                    unsigned long _data; /* Trap data */
                } _perf;
            };
        } _sigfault;
        
        /* SIGPOLL/SIGIO */
        struct {
            long _band;             /* Band event */
            int _fd;               /* File descriptor */
        } _sigpoll;
        
        /* Real-time signals */
        struct {
            __kernel_pid_t _pid;    /* Sending process PID */
            __kernel_uid32_t _uid;  /* Sending process UID */
            sigval_t _sigval;      /* Signal value */
        } _rt;
    } _sifields;
} kernel_siginfo_t;
```

**Delivery Process**:

### Signal Processing and Handling

#### `get_signal()` - Signal Processing Entry Point
```c

```

**Purpose**: Main function called by architecture-specific code to process pending signals

**Processing Steps**:
1. **Signal Dequeue**: Remove signal from pending queue
2. **Handler Lookup**: Find appropriate signal handler
3. **Special Processing**: Handle special signals (stop, continue, fatal)
4. **Handler Preparation**: Set up for signal handler execution
5. **Debugging Integration**: Support for ptrace and debugging

**Signal Action Types**:
```c
if (ka->sa.sa_handler == SIG_IGN) {
    /* Signal ignored */
    continue;
} else if (ka->sa.sa_handler != SIG_DFL) {
    /* User-defined handler */
    ksig->ka = *ka;
    return true;
} else {
    /* Default action */
    if (sig_kernel_ignore(sig))
        continue;
    if (sig_kernel_stop(sig)) {
        do_signal_stop(signr);
        continue;
    }
    /* Fatal signal processing */
    if (sig_kernel_coredump(signr))
        do_coredump(&ksig->info);
    do_group_exit(signr);
}
```

#### Signal Security Validation
```c
static bool sig_task_ignored(struct task_struct *t, int sig, bool force)
{
    /* SIGKILL and SIGSTOP may not be sent to global init */
    if (unlikely(is_global_init(t) && sig_kernel_only(sig)))
        return true;
        
    /* Unkillable processes */
    if (unlikely(t->signal->flags & SIGNAL_UNKILLABLE) &&
        handler == SIG_DFL && !(force && sig_kernel_only(sig)))
        return true;
}
```

**Security Mechanisms**:
- **init Protection**: Prevent killing system init
- **Unkillable Tasks**: Protect critical kernel tasks
- **Permission Validation**: Check signaling permissions
- **Namespace Isolation**: Maintain namespace security boundaries
